## ehviewer 安装解析包错误如何处理

## ehviewer 安卓 13/14 安装被阻止怎么办

安卓 13、安卓 14 之后系统权限收紧，小米、华为、vivo、oppo 国产手机会拦截外部 APK 安装。很多小白不知道这是系统安全限制，反复点安装都不成功。
